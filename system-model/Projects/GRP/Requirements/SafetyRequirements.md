# Elements

Safety requirements. These are typically the highest-priority requirements in a
public kinetic installation and drive independent verification (demonstration or
inspection), not just software tests.

### Pinch-Point Safety Stop

If a person or foreign object enters the moving-mechanism envelope, then the
system shall halt all actuation within 200 ms.
